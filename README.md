# Telegram-магазин БАДов

Покупательский Telegram-бот, отдельный закрытый админ-бот, SQLite и Python 3.11+ без сторонних зависимостей.

## Запуск и инициализация

Токены ботов и разрешённые Telegram ID администраторов хранятся в `.env` по образцу `.env.example`. Финансовые настройки и тексты меняются в админ-боте и сохраняются в SQLite.

### Инициализация базы данных и каталога
Для создания чистой базы и загрузки реальных товаров из каталога `data/media/`:

```powershell
python run.py seed-products --confirm-reset
python -X utf8 -u run.py bots
```

Команда `seed-products` считывает файл `data/media/Цены и название.txt`, находит соответствующие PNG-изображения в папке `data/media/` и заполняет каталог товаров с подтверждёнными ценами в RUB и Stars.

Для обновления схемы существующей базы без сброса данных:

```powershell
python run.py migrate
python -X utf8 -u run.py bots
```

`migrate` делает согласованную SQLite-копию рядом с базой (`shop-backup-*.sqlite3`), затем применяет миграции схемы. Повторный запуск не сбрасывает настройки и заказы.

Для карты и криптовалюты заполните менеджера, реальные реквизиты/адреса кошельков и курсы. До заполнения такие способы не предлагаются покупателям. Stars работают в реальном режиме.

## Покупатель

При первом входе бот предлагает выбрать страну доставки. Выбор сохраняется после перезапуска; изменить его можно кнопкой «Страна». Список стран ограничен заданным набором стран региона и управляется администратором.

Постоянная нижняя клавиатура: «Товары», «Корзина», «Мои заказы», «Техническая поддержка», «Отзывы», «Как купить?», «Страна», «Условия покупки».

Каталог представляет собой список названий с ценами, по 12 товаров на странице. Нажатие открывает описание, характеристики, фото/видео и кнопки покупки. «Назад к списку» возвращает на ту же страницу. Основная цена задаётся в RUB; для выбранной страны показывается местная сумма и рублёвый эквивалент, если задан курс.

В корзине можно менять количество и удалять позиции. Учёт остатков не ведётся: администратор вручную останавливает и возобновляет продажи товара. Оформление запрашивает имя, телефон, точный адрес или ссылку на выбранный ПВЗ Wildberries и комментарий; кнопка «Назад» возвращает к предыдущему шагу. Перед оплатой видны данные получателя и итоговые суммы. Карта и криптовалюта идут первыми, Stars последними. Если цена RUB/Stars, состав корзины, доставка, курс или демо-режим изменились после показа сумм, бот просит выбрать оплату заново.

«Мои заказы» содержит все заказы с постраничной навигацией и отдельной карточкой. Для неоплаченного перевода реквизиты видны непосредственно в карточке; кнопок «Реквизиты и менеджер» и «Чек отправлен» нет. Там можно открыть счёт Stars или отменить неоплаченный заказ. История доступна даже после выключения страны доставки. До 30 разных товаров в одном заказе; длинные сообщения разбиваются без потери позиций.

## Что настроить в админке

Откройте отдельного админ-бота и отправьте `/admin`. Доступ только разрешённым `ADMIN_IDS` и только в личном чате.

- **Товары:** название, описание, характеристики, две независимые цены RUB и Stars, фото/видео, остановка/возобновление продаж и архив. Настройки количества в наличии нет. RUB/KZT вводятся целыми; при вводе KZT фиксируется рублёвая цена с округлением вверх до рубля. Изменение RUB не меняет Stars и наоборот.
- **Заказы:** все страницы, фильтры, поиск по номеру/имени/телефону, подтверждение оплаты в два нажатия, отмена, завершение и внутренняя заметка. Промежуточные статусы и трек-номер убраны из кнопок. Старые данные заказов сохраняются.
- **Магазин → Настройки:** название, приём новых заказов, контакт поддержки, ссылка на отзывы.
- **Настройки → Тексты:** приветствие, инструкция покупки, условия покупки.
- **Настройки → Цены и доставка:** валюта ввода цен, отдельная стоимость доставки в целых RUB и Stars. Наценок и автоматического курса Stars нет.
- **Оплата:** единый экран для карты, криптовалюты, Stars, контакта менеджера, общих реквизитов/валюты карты, выбора общей или отдельной карты, перехода к странам/курсам и кошелькам. Настройки срока и демо-переключатель в админке отсутствуют.
- **Страны и курсы:** доступность каждой страны, курс в единицах местной валюты за 1 RUB, валюта перевода на карту и реквизиты для этой страны.
- **Криптокошельки:** добавление вариантов токен/сеть, адрес, рублей за один токен, включение/отключение. Подготовлены выключенные варианты USDT TRC20 и USDT ERC20.
- **Статистика:** число заказов и оплат, базовая стоимость оплаченных заказов в RUB и отдельные суммы по способам и валютам.
- **Платёжные проблемы:** оплаченные события Stars, которые нельзя сопоставить с активным заказом, например пришедшие после удаления. Администратор проверяет случай и отмечает ручное урегулирование. Эта отметка не возвращает деньги автоматически.
- **Проверка Stars:** заказы с начатой, но не завершённой оплатой. После сверки операций менеджер может в два нажатия подтвердить отсутствие платежа и освободить просроченный заказ.

Для очистки необязательного текста используйте «-». Для отмены ввода: `/cancel` или кнопка меню. Курсы задаются вручную; внешнего сервиса автообновления нет. Нулевой курс означает «не настроен». В обычном режиме вымышленных реквизитов нет; `reset-demo` включает явно обозначенную демонстрацию.

Токены ботов, список администраторов и путь к БД остаются в `.env`, они не доступны для редактирования покупателям или через обычные настройки магазина.

## Карта и криптовалюта

Для ручной оплаты обязательно задайте `@username` менеджера. Бот показывает только настроенные способы оплаты.

**Одна карта для всех стран:** в «Оплата» включите «Одна карта для всех стран», заполните «Общие реквизиты карты» и выберите валюту общей карты. Она применяется ко всем покупателям независимо от страны доставки. Для общей карты KZT курс берётся из Казахстана, для RUB курс равен 1. При выключении переключателя используются сохранённые реквизиты и валюта каждой страны; общая карта больше не подставляется. Старые заказы сохраняют исходные реквизиты и сумму. Криптокошельки общие для всех стран в обоих режимах.

Для карты выберите фактическую валюту, которую принимает счёт получателя. Для KZT и других валют нужен положительный курс. Если карта принимает RUB, местная валюта показывается как справочный эквивалент, а перевод требуется в RUB.

Криптовалюта работает как ручной перевод: бот показывает сумму, токен, точное название сети, адрес и контакт менеджера. Адреса ERC20/TRC20 проверяются по формату; это не проверка принадлежности адреса или баланса блокчейна. Итог округляется вверх до целого токена, как и остальные цены. Например, 1000 RUB при курсе 90 RUB/USDT = 12 USDT. Такое округление заметно для дорогих токенов: текущий сценарий ориентирован на USDT. Комиссию сети покупатель оплачивает отдельно. Для смены сети кошелёк сначала отключают, старый адрес при смене сети сбрасывается.

Покупатель отправляет чек или хеш транзакции менеджеру вместе с номером заказа. Менеджер проверяет фактическое поступление средств и подтверждает оплату в админке. Действия покупателя не меняют статус оплаты. При выборе карты или криптовалюты приходит одно сообщение с суммой, реквизитами, контактом менеджера и сроком. Нажатия старых кнопок обновляют сообщение на месте, без повторной отправки и без подтверждения чека. Старые заказы с уже отправленным ранее чеком сохраняют свой статус до решения менеджера.

Блокчейн и банковский счёт автоматически не опрашиваются. Реквизиты, менеджер, суммы, курс и демо-режим фиксируются в заказе; последующие изменения настроек действуют на новые заказы.

## Формулы

База = стоимость товаров в RUB + доставка в RUB.

```text
Stars = сумма(ручная цена Stars × количество) + доставка Stars
Карта = округление_вверх_до_целого(база × курс_валюты_за_RUB)
Крипта = округление_вверх_до_целого(база / рублей_за_токен)
```

Пример товара: `1000 RUB`, отдельно `80 Stars`. При курсе `5 KZT/RUB` карта = `5000 KZT`. Изменение цены до `1500 RUB` оставляет `80 Stars`, пока администратор не изменит Stars вручную.

Старые настройки комиссий/наценок игнорируются и отсутствуют в админке. Автоматической компенсации банковских, сетевых комиссий и стоимости вывода Stars нет. Цены и реальные условия расчётов определяет владелец магазина.

[Telegram описывает Stars как оплату цифровых товаров и услуг](https://core.telegram.org/bots/payments-stars); для физических товаров есть [отдельная документация](https://core.telegram.org/bots/payments). Встроенный способ Stars сохранён как опциональный и выключается администратором.

## Срок оплаты и сохранность

Срок новых заказов фиксирован: 3 часа. Он указан покупателю с точным временем UTC и не меняется из админки. Ранее созданные заказы сохраняют исходный срок. Товар доступен для заказа, пока администратор не остановит его продажи.

Фоновая проверка выполняется раз в минуту, в том числе без входящих сообщений. После срока неоплаченный заказ и его позиции удаляются. Покупателю отправляется уведомление; при сетевой ошибке уведомление остаётся в очереди. После перезапуска обработка просроченных заказов продолжается по сохранённым срокам. Старое поле количества сохранено в SQLite для совместимости и не влияет на покупки, отмену и удаление заказов.

Оплаченные заказы, чеки на проверке и заказы с одобренным pre-checkout Stars не удаляются. Последние после срока получают статус «Проверка платежа Stars». Пока результат не выяснен, отмена блокируется; менеджер сверяет поступления и вручную снимает ожидание только при отсутствии оплаты. В случае неопределённости заказ нужно сохранить.

Перед Stars-платежом проверяются покупатель, валюта, сумма, срок, статус и доступность метода. Одновременное повторное подтверждение счёта блокируется на минуту. Подтверждённые платежи сохраняются идемпотентно по идентификатору Telegram; повтор события не создаёт вторую транзакцию и не меняет статус доставленного заказа. Поздние или несовпадающие платежи сохраняются в «Платёжных проблемах». Для таких событий может сохраняться техническая связь с номером удалённого заказа без восстановления его позиций.

Только `PAYMENT_MODE=mock` имитирует успешную оплату Stars для локальной проверки. В рабочем режиме используйте `PAYMENT_MODE=stars`.

Уведомления администратору о Stars-платежах сохраняются транзакционно в SQLite и повторяются после ошибки сети. Покупателю не отправляются дополнительные сообщения об успешной оплате и смене статуса менеджером: результат доступен в «Мои заказы», квитанцию Stars выдаёт Telegram. Исключения — истечение срока и платёж, который требуется проверить вручную. Доставка служебных уведомлений «как минимум один раз»: авария между отправкой Telegram и фиксацией ответа может дать повтор сообщения, но не повторную финансовую транзакцию.

Временные ошибки `getMe` и polling повторяются; 401/404/409 останавливают оба бота. При Ctrl+C процесс ждёт завершения текущих обработчиков и сетевых запросов. Резервные копии содержат персональные данные, храните их закрыто.

## Проверки

```powershell
python -m unittest discover -s tests
python -m compileall -q src
python run.py demo
```

Тесты используют временные базы и поддельные Telegram-клиенты. Они проверяют независимые RUB/Stars, округление, отсутствие наценок, демо-оплаты, сброс/backup/блокировку процесса, переключение в рабочий режим, изменение котировок, ручную остановку продаж, срок оплаты, защиту начатого платежа, очередь уведомлений, навигацию, права и настройки. Реальные списания и блокчейн-транзакции тесты не выполняют.
